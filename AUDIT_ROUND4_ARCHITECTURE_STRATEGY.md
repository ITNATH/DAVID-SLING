## 1. State Memory Persistence (9+ timeframes)

  per TF from the builder — the fusion brain (`NineLayerFusionBrain`) receives all 9

## 2. Session Clocks & Overlap Synchronization
- `core/session_epoch_manager.py:28-44` `epoch_at()`: ASIA 00–07, ASIA_LONDON_OVERLAP
  07:00–08:00, LONDON 08–13, LONDON_NY_OVERLAP 13–16, NY 16–22, OFF_HOURS 22–24 UTC.
- **GAP G32 (lapse):** the branch `if 14 <= h < 15: return TEN_AM_CLUB` (line 41) is
  **unreachable** — it is shadowed by `if 13 <= h < 16: return LONDON_NY_OVERLAP`
  (line 39). `TEN_AM_CLUB` can never be returned; `primary_phase()` maps overlaps to
  "OVERLAPS" so the 6-phase model still works, but the NY-10AM killzone is dead code.
- Verdict: **CONDITIONAL PASS** (boundaries correct; TEN_AM_CLUB branch ordering bug).

## 3. Data Leakage & Lookahead (hard bar-close isolation)
- **GAP G31 (critical lapse):** `CandleBuilder.candles()` (`data/market.py:110-116`)
  appends the **forming (unclosed) candle** to the returned series:
  `out.append(forming)`. `DecisionPipeline.candles_by_tf` → `intelligence.analyze` →
  `fusion.fuse` therefore consume the live bar, and `_pipeline_loop`
  (`runtime.py:333-355`) dedups on `m1[-1].open_time`, which is the forming M1 bar — the
  pipeline re-runs many times on the same unclosed bar. Blueprint rule: unclosed candles
  must never pollute historical matrices. **Verdict: FAIL on leakage** (fix: serve
  `closed` only to L3–L9, keep forming for price display only; dedup must fire on candle
  *close*, i.e. when the bucket rolls).

## 4. Probabilistic / Predictive Horizon Outputs (5m→8H forward windows)
- **GAP G34 (critical):** `HypothesisEngine.build` (`hypothesis/engine.py:23-44`) emits
  only a directional thesis + invalidation price (`HypothesisState`); `PrecisionEngine`
  (`precision/engine.py:18-46`) emits tier grades. **No module produces forward
  probability distributions for 5m/15m/30m/1H/4H/8H windows** (grep for prob/forward/
  horizon across hypothesis/precision/signal → none). **Verdict: CRITICAL FAIL** vs the
  required schema; roadmap item.

## 5. Engine Peer Architecture
